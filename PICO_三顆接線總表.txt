PICO 三顆控制系統－接線總表
更新：依目前專案程式碼分析（dbr4_bridge / small_sweet / pico_drv8825）

======================================================================
0. 系統架構（畫圖時先照這個）
======================================================================

DBR4 接收器 --CRSF 420000 baud--> Pico #1：DBR4 橋接 Pico
                                       |
                                       | GP4 TX，115200 baud，14-byte v2 control packet
                                       +---------------------> Pico #2：四馬達整合 Pico，GP1 RX
                                       |
                                       +---------------------> Pico #3：TMC2240 步進 Pico，GP1 RX

所有 Pico GND、各馬達電源負極、各驅動器 GND 必須共地。
注意：資料線是「橋接 GP4 一分二」；不是 Pico 串接。


======================================================================
1. Pico #1：DBR4 橋接 Pico
   專案：D:\ctrl_v_mix\dbr4_bridge
   韌體環境：dbr4_bridge
======================================================================

用途：
- 從 DBR4 接收器讀取 CRSF 遙控資料（420000 baud）。
- 每 20 ms 將自訂 v2 控制封包送給四馬達 Pico 與步進 Pico（115200 baud）。

GPIO 接線：

  Pico #1 GPIO        要接的東西                         方向/用途
  -----------------------------------------------------------------------------
  GP1 (實體 Pin 2)    DBR4 接收器 CRSF TX               RX，420000 baud
  GP0 (實體 Pin 1)    不必接                            UART0 TX，程式沒有使用
  GP4 (實體 Pin 6)    分接至 Pico #2 GP1 與 Pico #3 GP1 TX，115200 baud
  GP5 (實體 Pin 7)    不必接                            UART1 RX，程式會丟棄資料
  GND                 接 DBR4 GND、Pico #2 GND、Pico #3 GND 共地
  USB                 接電腦/5V USB                     燒錄、除錯、供電（測試用）

DBR4 接收器：
- 接收器 TX -> Pico #1 GP1（TX 對 RX）。
- 接收器 GND -> Pico #1 GND。
- 接收器 VCC 依 DBR4 接收器規格供電；不要從程式碼推論其 VCC。
- CRSF 是 3.3 V 邏輯，請勿將 5 V UART 直接接進 Pico GPIO。


======================================================================
2. Pico #2：四顆編碼 DC 馬達 + 5 顆 TT + 無刷 ESC + 伺服 + US-100
   專案：D:\ctrl_v_mix\small_sweet
   韌體環境：four_motor_rc
======================================================================

用途：
- 接收橋接 Pico 的遙控封包。
- 控制四顆麥克納姆/編碼 DC 馬達、5 顆 TT 閘門馬達、1 顆無刷 ESC、1 顆位置伺服。
- 讀取 US-100 超音波距離。前方有效距離 <= 15 cm 時擋住前進；
  有效距離 >= 35 cm 時解除擋住前進。

共用遙控匯流排：

  Pico #2 GPIO        要接的東西
  -----------------------------------------------------------------------------
  GP1 (實體 Pin 2)    Pico #1 GP4（橋接資料 TX）
  GP0 (實體 Pin 1)    不必接（UART TX；目前未使用）
  GND                 必須接 Pico #1 GND，並與所有驅動器電源負極共地

四顆編碼/直流馬達驅動器（每一顆驅動通道使用 PWM + DIR）：

  車輪                 PWM GPIO             DIR GPIO             驅動器端
  -----------------------------------------------------------------------------
  右前 FR              GP6  (Pin 9)         GP7  (Pin 10)        PWM / DIR
  左前 FL              GP8  (Pin 11)        GP9  (Pin 12)        PWM / DIR
  右後 BR              GP10 (Pin 14)        GP11 (Pin 15)        PWM / DIR
  左後 BL              GP12 (Pin 16)        GP13 (Pin 17)        PWM / DIR

  注意：程式輸出 PWM 為 20 kHz、範圍 0..255；馬達驅動器的電源與 Pico GND 必須共地。
  馬達本體接到驅動器輸出端；不可直接接 Pico GPIO。

US-100 超音波（必須拔除 US-100 的模式跳線，使用 TRIG/ECHO 模式）：

  US-100 腳位          Pico #2
  -----------------------------------------------------------------------------
  VCC                  3V3（為確保 Echo 是 3.3 V）
  GND                  GND
  Trig / TX            GP2（實體 Pin 4）
  Echo / RX            GP3（實體 Pin 5）

  重要：若 US-100 裝著跳線，是 UART 模式，不能使用本程式的 GP2/GP3 接法。
  重要：不要在 Echo 直接接 Pico 時以 5 V 供電；5 V Echo 會傷 Pico GPIO。

無刷馬達 ESC（目前整合版使用這組，不是 brushless_ch10 的 GP7）：

  ESC 線              Pico #2
  -----------------------------------------------------------------------------
  訊號線（通常白/黃）  GP14（實體 Pin 19）
  訊號地（通常黑/棕）  GND
  ESC 主電源          獨立電池/電源；負極必須與 Pico GND 共地

位置伺服馬達（DS3240）：

  伺服線              Pico #2
  -----------------------------------------------------------------------------
  訊號線              GP15（實體 Pin 20）
  電源正極            獨立 5~6 V BEC/伺服電源（依伺服規格）
  電源負極            與 Pico GND 共地

  警告：不要用 Pico 3V3 或 USB 直接供應大扭力伺服電源。

5 顆 TT 馬達（經 3 片雙路 L9110S；每顆使用 IA / IB）：

  TT 馬達             Pico #2 IA           Pico #2 IB          L9110S 端
  -----------------------------------------------------------------------------
  TT1                 GP16 (Pin 21)        GP17 (Pin 22)       IA / IB
  TT2                 GP18 (Pin 24)        GP19 (Pin 25)       IA / IB
  TT3                 GP20 (Pin 26)        GP21 (Pin 27)       IA / IB
  TT4                 GP22 (Pin 29)        GP26 (Pin 31)       IA / IB
  TT5                 GP27 (Pin 32)        GP28 (Pin 34)       IA / IB

  每片 L9110S：VCC 接其所需馬達電源、GND 與 Pico GND 共地、馬達接 OUTA/OUTB。
  TT 馬達電源不可由 Pico 供應。

遙控功能對應（Pico #2）：
- CH1：左右平移。
- CH2：前後。
- CH4：旋轉。
- CH5：總安全啟用；開機或失聯後必須先切到低，再切高。
- CH7：位置伺服；目前以較快速度 jog。
- CH9：TT 閘門觸發。
- CH10：無刷 ESC 節流；CH5 開啟前，CH10 必須先在最低位置。
- CH8：只轉送給 Pico #3 步進；Pico #2 不以它控制自身馬達。


======================================================================
3. Pico #3：TMC2240 + 42 步進馬達 Pico
   專案：D:\ctrl_v_mix\pico_drv8825
   韌體環境：pico
======================================================================

用途：
- 經 SPI 設定與檢查 TMC2240。
- 經 STEP/DIR/EN 控制 42 mm 步進馬達。
- 接收 CH5 + CH8 控制；CH5 啟用且 CH8 約 +97 時，正轉 200 脈波/秒。

共用遙控匯流排：

  Pico #3 GPIO        要接的東西
  -----------------------------------------------------------------------------
  GP1 (實體 Pin 2)    Pico #1 GP4（橋接資料 TX）
  GP0 (實體 Pin 1)    不必接（UART TX；目前未使用）
  GND                 接 Pico #1 GND；也必須接 TMC2240 GND 與馬達電源負極

TMC2240（依你提供、左側有 EN/MOSI/SPI-CLK/CS/MISO/CLK/STEP/DIR 的板子絲印）：

  Pico #3 GPIO         TMC2240 腳位
  -----------------------------------------------------------------------------
  GP2  (Pin 4)         STEP
  GP3  (Pin 5)         DIR
  GP4  (Pin 6)         EN / ENN（低電位啟用）
  GP8  (Pin 11)        MISO
  GP9  (Pin 12)        CS / CSN
  GP10 (Pin 14)        SPI-CLK / SCK
  GP11 (Pin 15)        MOSI / SDI
  GND                  CLK（目前接法，將 CLK 拉低）
  3V3 (Pin 36)         VIO
  GND                  邏輯 GND（TMC2240 最下方 GND）

TMC2240 馬達/電源側：

  要接的東西           TMC2240 腳位
  -----------------------------------------------------------------------------
  外部馬達電源正極     VM
  外部馬達電源負極     VM 旁 GND
  步進馬達線圈 A       A1、A2
  步進馬達線圈 B       B1、B2
  AIN、DIAG            不接（本程式未使用）

  必要事項：
  1. 馬達電源負極、TMC2240 GND、Pico #3 GND 三者共地。
  2. VM/GND 附近裝 >=100 uF 電解電容，並注意正負極。
  3. 所有 SPI 線都必須接；只接 EN/STEP/DIR 時，SPI IOIN=0x0，程式會拒絕啟動。
  4. 先接好馬達線和電源再上電；不要帶電插拔馬達插頭。

遙控功能對應（Pico #3）：
- CH5：安全啟用。
- CH8 約 +97：步進正轉，200 STEP pulses/s。
- CH8 約 -97、置中、遙控失聯：停止並關閉驅動器。

USB 測試指令（115200 baud）：
- i        重新測試 TMC2240 SPI；必須顯示非 0x0 / 非 0xFFFFFFFF 的 IOIN。
- p 200    USB 指令持續正轉 200 脈波/秒。
- p -200   USB 指令持續反轉 200 脈波/秒。
- s        立即停止並關閉驅動器。

4. brushless_ch10 專案的定位（不是目前三顆整合系統要再加的第四顆 Pico）
   專案：D:\ctrl_v_mix\brushless_ch10
======================================================================

這是「單獨測試無刷 ESC」用的替代程式：
- DBR4 接收器 CRSF TX -> GP1（420000 baud）。
- ESC 訊號 -> GP7。
- GP0 是 UART TX，未用。
- CH5 啟用；CH10 控制節流。

注意：目前整合系統的無刷 ESC 已由 Pico #2 / small_sweet 控制，訊號是 GP14。
因此不要同時把同一顆 ESC 訊號線接到 GP7 與 GP14，也不要把這份程式當作第四顆必要 Pico。


======================================================================
5. 電源與畫線安全規則
======================================================================

1. Pico GPIO 全部都是 3.3 V 邏輯；不可直接接 5 V 訊號。
2. USB 是 Pico 程式/低功耗供電；DC 馬達、TT 馬達、伺服、ESC、步進馬達都要用合適的外部電源。
3. 不同電源可以有不同正電壓，但「所有訊號相關的負極/GND」必須共地。
4. 馬達電源線與細訊號線分開走，步進 VM 端必須有電解電容。
5. 接線或換馬達線前，先拔掉外部馬達電源；不要熱插拔 TMC2240 馬達線。
6. 三顆 Pico 的 USB 可分別接電腦測試，但外部電源 GND 仍需正確共地。
